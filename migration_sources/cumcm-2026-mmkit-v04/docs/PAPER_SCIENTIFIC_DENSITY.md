# Paper Scientific Density (v0.2 P1)

本文件定义论文科学密度（公式链、模型评价平衡、视觉锚点）的**指导性**审计口径。
目标：帮助作者写出完整、可追溯、可重建的科学论证；不是机械扣分规则。

## 1. 公式链（Equation Chain）

每个实质性模型小节应尽量包含以下环节（按 config/paper_quality.yaml 的 require_chain）：

1. 定义：变量/状态/符号定义（含量纲、单位、取值范围）。
2. 机制/概率模型：模型机理由什么概率或机制刻画（分布、随机过程、机制方程）。
3. 目标函数或似然：优化目标 / 似然 / 目标泛函。
4. 约束/状态转移：可行域、动力学、守恒、边界条件、马尔可夫转移等。
5. 求解准则：如何求解（estimator、算法、判定准则、收敛条件）。
6. 评价/稳健性指标：用什么指标评价（RMSE/MAPE/覆盖率/敏感性…）。

规则：
- 缺环时若在本题无定义（如无约束问题），允许省略但需在模型说明中注明理由（不奖励公式堆砌）。
- 公式必须与可重建代码一致：每个关键公式应有代码对应与数值验证。
- 禁止只展示最终数值而无机制说明。

## 2. 模型评价平衡（Model Evaluation Balance）

写作质量目标（非字符数定律）：

- 优点：约 67-75% —— 具体、可验证，如：
  - 结构忠实性（问题到模型的结构映射）
  - 概率/统计口径精确处理
  - 可解释性
  - 相对 baseline 的明确增益
  - 可复现性（随机种子/输入哈希/依赖冻结）
  - 不确定性传播或误差刻画
  - 稳健性/敏感性/交叉验证
- 局限：约 25-33% —— 诚实列出：假设强度、数据限制、样本外风险、计算成本、无法验证的部分。

禁止：
- 空泛的“准确率高、鲁棒性强、适用广泛”。
- 虚构优点或无证据 superiority 声称。
- 把局限包装成优点。

## 3. 视觉锚点（Visual Anchor）

建模/结果主体区域：每 1.0-1.5 页至少一个**有意义**的视觉锚点（图、表或关键公式组）。
摘要、假设、参考文献、结论等区域允许偏离。参考密度不是每页强制一图。

## 4. 审计工具

运行：powershell 执行 .venv\Scripts\python.exe scripts\audit_paper_density.py <main.tex>

输出为按节/页的报告（方程数、图数、表数、锚点密度、长文本段、评价平衡、占位引用、
工程标识符泄漏），只作 GUIDANCE，不作硬性失败判定；由人工结合 config/paper_quality.yaml 裁决。
